# SocietyCore

**Mega systems pack** for Minecraft Bedrock **1.26+** — civic, work, industry, mobility, risk, soft infrastructure, consumer life, and institutions in one addon.

## Modules (v1.0.0)

| Area | Systems |
|------|---------|
| **Civic** | Court (tickets, cases, judgments, garnish), Tax, Votes, Emergency 911 |
| **Work** | Job board, employment, certificates, strikes |
| **Industry** | Market tick (ore/crop/fuel), building permits, waste/landfill |
| **Mobility** | Plates, hotel rooms, flight plans, port containers |
| **Risk** | Credit bureau, liens, notary contracts, fraud desk |
| **Soft** | News wire, weather service, survey parcels, business-day clock |
| **Consumer** | Leases, subscriptions, warranties, loyalty points |
| **Institutions** | Central bank prime, FX quotes, clearing queue |

## Install

1. [SocietyCore-v1.0.0.mcaddon](https://github.com/blocklogic-studios/societycore/releases/download/v1.0.0/SocietyCore-v1.0.0.mcaddon)
2. Enable **Resources + Behavior**
3. **Beta APIs**

Optional: FinanceCore (garnish / tax debit), CarrierCore (news bridge), PowerCore (outage headlines).

## Play

- Place **Civic Hub** or use **Civic Tablet**
- Or use specialty desks (court, tax, job board, etc.)

## Studio stack

CarrierCore · FinanceCore · PowerCore · PostalCore · **SocietyCore**
